Campus Event Planner

Aplicação em Python, executada via console, desenvolvida para gerenciar eventos do IFConecta/IFB. O sistema permite adicionar, listar, buscar e excluir eventos, filtrar por categoria, marcar eventos como participados e gerar relatórios com estatísticas.
O projeto foi desenvolvido em equipe, utilizando Git e GitHub para colaboração através de branches e Pull Requests.
